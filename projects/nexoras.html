NEXORAS

NEXORAS is a community-oriented digital platform concept designed to connect people to create, learn, act and earn through shared opportunities and collaboration.

In developmentReact 19TypeScriptASP.NET CorePostgreSQLRedisSignalR

Problem space and product vision

People often discover communities, learning resources, missions, skills and opportunities across disconnected services. NEXORAS explores a unified action network where people can connect, create, learn, act and earn through purposeful collaboration.

The portfolio describes this as a product direction and architecture, not a launched global social network. The focus is on clear user journeys, maintainable backend boundaries and features that can grow without overstating current delivery.

Engineering approach

  • React 19, TypeScript and Tailwind CSS for the web experience.
  • API gateway direction using Node/Express with an ASP.NET Core application backend.
  • Clean Architecture separation across Domain, Application, Infrastructure and API.
  • MediatR/CQRS patterns for organizing use cases and application requests.
  • PostgreSQL for persistence, Redis for caching, and SignalR for real-time updates where implemented.
