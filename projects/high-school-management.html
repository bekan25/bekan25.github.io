High School Management System

A full-stack school administration application organized as an npm-workspaces monorepo, with separate frontend, backend, database and shared-code areas.

Project structure

The repository README identifies a React/Vite frontend, Express API, PostgreSQL migration and seed scripts, and shared TypeScript types. This structure supports clear boundaries between the interface, API and data layer.
