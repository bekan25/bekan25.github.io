MERKATO

A trust-first Ethiopian marketplace project intended to connect buyers and merchants through a practical digital shopping experience, starting with a controlled Addis Ababa pilot.

In developmentAngular 18ASP.NET Core 10PostgreSQL

Problem and product direction

MERKATO explores how local buyers and merchants can discover products, manage orders and build trust through one marketplace experience. The current product direction prioritizes buyer and merchant workflows, clear order states, safer account roles and transparent payment status.

The repository documents a preview baseline. Live provider payments, automated settlements and external courier integrations are not enabled; this case study does not present them as live services.

Architecture overview

The repository describes an Angular web client backed by an ASP.NET Core API and PostgreSQL persistence through Entity Framework Core.

Engineering focus

  • Buyer and merchant registration with role-aware access.
  • Product catalogue, cart and buyer order workflows.
  • Merchant product and order management.
  • Payment initiation records and idempotency-oriented design.
  • Clear release gates for external payments, settlement and delivery integrations.
